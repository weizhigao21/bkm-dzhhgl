# 宝可梦多账号管家 `v1.7`

Pokemon66 免费加速服务的多账号管理工具，支持一键登录、多训练师切换、批量兑换码、订阅地址复制、Token 过期自动登录等功能。

## 快速开始

```bash
git clone https://github.com/weizhigao21/bkm-dzhhgl.git
pip install requests
python main.py
```

或直接下载 [dist/宝可梦多账号管家.exe](dist/宝可梦多账号管家.exe) 运行。

## 功能

| 功能 | 说明 |
|------|------|
| 🔑 账号登录 | 邮箱 + 密码一键登录，自动获取 Token，支持自动重登录 |
| 👥 多训练师管理 | 支持多账号切换，数据本地持久化 |
| 🗑️ 右键删除 | 训练师卡片右键即可删除，自动保存 |
| 📊 订阅查询 | 查看套餐名称、到期时间（日期+剩余天数+颜色提醒）、流量使用等 |
| 📋 复制订阅地址 | 一键复制到剪贴板 |
| 📝 最近兑换 | 训练师信息展示最近一次兑换的时间与兑换码 |
| 🎫 兑换码使用 | 单个账号兑换，输入兑换码一键使用 |
| 🚀 全部兑换 | 一键给所有训练师并行兑换，结果汇总展示 |
| 📜 运行日志 | 弹窗查看实时日志，支持清空 |
| 🚀 启动加载 | 打开程序自动显示第一个训练师信息 |
| 🖥️ 屏幕居中 | 启动时窗口自动居中显示 |
| 🔄 自动重登录 | Token 过期自动用保存的密码重新登录（300 秒冷却） |
| 📝 兑换码历史 | 自动记录使用过的兑换码，下次可快速选择 |
| 📧 邮件通知 | SMTP 配置，定时检查流量，低于阈值自动发邮件提醒 |
| 📊 每日报告 | 每天定时发送所有账号流量汇总邮件 |
| ⚙️ 设置中心 | 邮箱通知 / 开机自启动统一配置 |
| 🚀 开机自启 | 通过 Windows 注册表实现开机自动启动 |

## 项目文件

| 文件 | 说明 |
|------|------|
| `main.py` | 程序入口 |
| `src/constants.py` | 常量定义（版本号、API、颜色、加密密钥等） |
| `src/utils.py` | 工具函数（解密、密码加密/解密、网络表单构建等） |
| `src/widgets.py` | 弹窗组件（登录弹窗、日志弹窗、兑换结果弹窗） |
| `src/user_list_item.py` | 训练师列表项 UI 组件（卡片样式、悬停/选中状态） |
| `src/app_ui.py` | 应用 UI 构建（侧边栏、信息卡片、兑换区域布局） |
| `src/app_network.py` | 网络请求层（订阅查询、自动重登录、单个/批量兑换） |
| `src/app.py` | 核心业务逻辑（状态管理、事件处理、配置持久化） |
| `src/notify.py` | 邮件通知模块（SMTP 发送、后台定时流量检查） |
| `src/autostart.py` | 开机自启动管理（Windows 注册表） |
| `src/settings_dialog.py` | 设置弹窗（邮箱通知 / 开机自启配置） |
| `config.json` | 用户配置（密码加密存储） |
| `README.md` | 项目说明 |
| `1.ico` | 应用图标 |

> 项目地址：[github.com/weizhigao21/bkm-dzhhgl](https://github.com/weizhigao21/bkm-dzhhgl)

## 打包说明

```bash
pyinstaller --onefile --windowed --icon=1.ico --add-data "1.ico;." --name "宝可梦多账号管家" main.py
```

输出文件在 `dist/` 目录下。将 `.exe` 放到任意文件夹运行即可，配置自动保存在同级目录。

## 注意事项

- 兑换码使用后需要手动点击「刷新」查看最新流量
- 密码使用机器绑定加密存储在本地 `config.json`
- 仅适用于 Pokemon66 平台（love.52pokemon66.cc）
